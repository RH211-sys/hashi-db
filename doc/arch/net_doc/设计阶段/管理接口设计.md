## 1. 目的与边界

管理接口负责服务启停、客户端连接维护、指标查询和明确授权的存储维护请求。服务停止采用立即关闭，不做排空：停止网络接入并关闭连接，未派发请求丢弃，已经开始执行的业务继续运行但不再向已关闭连接返回响应。管理接口与客户端数据命令共享必要的协议和执行边界，但权限、资源额度、审计和故障语义必须隔离；数据读写权限不自动包含管理权限。

管理入口分为本地入口和远程管理命令。本地入口由宿主进程或受信任的本机控制面发起，不伪造 TCP 客户端、不创建虚假连接，也不经过连接事件循环。远程管理命令通过 MYDB 网络协议、正常连接解析、身份认证和管理权限检查进入统一的管理执行边界。

本文件描述目标契约，不能视为当前已有管理能力。ConnectionRegistry 与管理命令执行尚未闭环。管理操作不能绕过存储层现有线程归属、生命周期与异步接口，也不得令网络事件循环等待磁盘任务。

## 2. 管理能力

| 能力 | 本地入口 | 远程入口 | 约束 |
|---|---|---|---|
| 启停与立即停止 | 宿主进程生命周期接口 | 远程不提供服务启停命令 | 停止网络接入并关闭连接；不做排空，未派发请求丢弃，已开始业务继续执行但不再响应 |
| 读取生效配置 | 允许只读查询 | 可选，只读管理员权限 | 返回脱敏配置，不显示密码、令牌或私钥 |
| 修改运行期配置 | 本轮不纳入目标接口 | 不通过远程命令修改 | 配置改变方式和可变参数须经后续需求评审；监听地址、证书、身份源、协议及资源硬上限不由本管理契约默认为可热改 |
| 查询连接 | 允许有限快照 | CLIENT_LIST（查询连接快照），管理权限 | 返回采集时刻的快照，不含请求正文、键值和秘密 |
| 关闭连接 | 按稳定连接标识请求立即关闭 | CLIENT_KILL（按连接标识请求关闭客户端连接），连接管理员权限 | 由连接所属事件循环执行；清除未派发请求；已开始业务继续但不再响应 |
| 查询指标 | 允许 | STATS（读取运行统计）或专门的只读管理员查询 | 标注采集时间和来源，指标不是事务状态 |
| 凭据、角色管理 | 本设计不规定管理命令或在线管理能力 | 不开放远程自助提权或修改首位管理员 | 凭据来源、生命周期和管理入口由后续安全需求另行确认 |
| 持久化、刷盘、重写 | 明确授权的本地维护请求 | PERSIST（请求持久化）、FLUSH（清理并刷盘）、REWRITE（整理持久化文件），维护权限 | 遵循存储接口语义，不直接操作存储内部线程 |

本地服务停止由宿主进程或本机控制面触发；不提供远程停服命令。术语说明：排空是停止新工作后等待已接收工作完成的停机方式；本设计明确不排空。

若部署不希望远程提供管理能力，可整体关闭远程管理命令而保留本地入口。远程 CLIENT_LIST（查询连接快照）和 CLIENT_KILL（按连接标识请求关闭客户端连接）必须采用命令级授权。STATS（读取运行统计）响应清楚区分网络与存储指标来源。

### 2.1 连接快照

连接快照目标字段包括稳定连接标识、对端地址、连接持续时间、连接状态、协商协议版本、按策略脱敏的认证主体、当前请求编号和命令类别、输入/输出缓冲字节数以及背压状态。快照不承诺跨连接原子一致，不包含密码、令牌、原始帧、请求数据值或证书材料。结果条目数受服务端固定上限约束；超过限制时不增加协议分页字段，返回明确结果。CLIENT_LIST（查询连接快照）的具体连接记录编码和字段布局属于未冻结的协议扩展，须后续单独评审。

### 2.2 关闭连接

通过稳定连接标识和内部连接代际定位目标，不采用文件描述符作为远程身份。CLIENT_KILL 的目标语义为立即请求关闭；目标不存在或已关闭时返回明确结果，重复请求应幂等。关闭时丢弃尚未派发的请求，已经开始执行的业务继续运行但不再尝试向此连接发送响应。客户端断开或管理关闭不意味着存储操作回滚。

## 3. 接口与响应约定

管理请求按顺序执行结构校验、身份认证、动作授权、容量准入、业务执行、审计和结果编码。错误应区分非法参数、认证拒绝、授权拒绝、目标不存在、容量不足、状态冲突、审计不可用和内部依赖失败。返回原请求关联标识、稳定结果类别及有界说明；不得回传堆栈、文件路径、凭据或内部存储错误编号。

远程入口遵守协议 v1：CLIENT_KILL（按连接标识请求关闭客户端连接）使用连接标识字段；CLIENT_LIST（查询连接快照）不接受查询字段；STATS（读取统计）可带范围字段；PERSIST（请求持久化）可带键且缺省代表全部；FLUSH（执行清理并刷盘）和 REWRITE（整理持久化文件）不带参数。CLIENT_LIST 结果只由服务端固定上限约束，超过限制时以明确结果表示，不添加分页/过滤参数。具体连接记录字段和响应数据编码仍需另行进行协议兼容性评审，本轮不规定嵌套记录字段。字段编号及协议命令定义集中维护于[需求文档](./需求文档.md#22-协议与命令范围)。

本地入口采用类型明确的管理请求，不模拟网络帧，但与远程入口共享动作验证、授权策略和业务执行逻辑。监听地址、证书与密钥、身份源等敏感配置只允许可信本地控制面管理，不提供远程任意配置写入命令。

服务停止和连接关闭须依据服务当前状态执行。重复停止或关闭不增加副作用；状态冲突返回明确结果。停服不执行排空：先停止接受新连接并停止网络 I/O，丢弃所有尚未派发的请求；此前已交给执行层的请求继续运行，但因连接已关闭不再返回响应。派发前若服务端已经观察到客户端连接关闭或重置，则直接丢弃该请求，不交给业务执行层；响应发送前若已观察到连接关闭，则丢弃待发响应。服务端无法保证客户端进程在最近一次 I/O 检查后仍然存活，断开信号也可能晚于存储操作开始到达。PERSIST、FLUSH、REWRITE 是否幂等由存储业务接口决定，网络管理层不得自行承诺可安全重试。

## 4. 权限与审计

每条远程管理命令必须单独检查权限，不能把“已认证”视作拥有全部管理权。具体角色名称和权限矩阵不在本轮冻结；部署策略须显式授予相应管理动作，数据读写许可不得隐式扩大为管理许可。

ACL（访问控制列表）根据已认证主体、请求动作和上下文判断许可或拒绝；拒绝优先。认证失败、ACL 缺失或策略服务不可用时，需要认证的远程命令按拒绝处理。网络层不得仅因请求中有 AUTH 或用户名字段就标记身份已验证。本地入口的信任来源应由宿主调用上下文明确提供，不能由远程字段伪造。

所有管理入口的请求均应形成审计事件，包括远程和本地操作、只读查询、拒绝和失败请求；审计至少记录时间、来源入口、主体（未认证请求标记为未认证）、动作、目标标识、结果和请求关联标识。审计不得记录密码、令牌、私钥、完整数据值或原始帧。远程管理请求在审计不可用时一律失败关闭，不得执行查询或副作用操作。本地管理请求同样写入审计；审计不可用时也拒绝管理请求。审计介质、访问控制和保留期限属于全局安全策略。

## 5. 安全及资源控制

1. 管理命令使用独立在途额度及单次响应大小上限；容量不足时返回忙或过载结果，不得进入无界队列。
2. 连接列表和指标扫描均有条目数、扫描工作量及编码字节上限；列表不定义分页字段。
3. 关闭连接、停止服务、刷盘和重写等高成本操作受并发限制；同目标重复请求可合并或按状态冲突拒绝。
4. 对远程管理按主体、来源地址和动作限频；认证失败亦纳入防暴力尝试策略。
5. 管理执行器异步完成可能耗时的业务，网络事件循环不得等待磁盘或存储任务。
6. TLS（传输层安全协议）为生产默认要求；初始化或证书错误时不得降级。明文只允许显式开发/测试授权，非回环监听另需许可。
7. 管理入口不暴露秘密、未脱敏的配置、完整数据或内部诊断堆栈。

## 6. 术语说明

- 管理面：服务运维和控制能力集合，与普通客户端数据命令在授权、资源和审计上分隔。
- 本地管理入口：进程内或受信任本机控制面发起的管理请求，不经远程 TCP 模拟。
- 远程管理命令：通过 MYDB 协议接收并经过认证及命令级权限检查的管理请求；MYDB 协议是项目自定义的版本化网络请求/响应格式。
- ConnectionRegistry：按稳定连接标识提供有限快照并向连接所属事件循环投递关闭请求的模块抽象。
- 连接代际：区分连接实例和迟到结果的内部标记，不由客户端指定。
- ACL：访问控制列表，根据主体、操作和上下文决定是否授权。
- MYDB 网络协议：myDB 自定义的版本化请求/响应格式；客户端管理命令使用其中定义的字段规则。
- CLIENT_LIST：查询连接快照的网络命令；本轮不定义快照记录的线格式。
- STATS：读取运行统计信息的网络命令。
- CLIENT_KILL：按连接标识请求关闭客户端连接的网络命令。
- PERSIST：请求将指定数据或全部待持久化内容写入存储介质的维护命令。
- FLUSH：请求执行清理并刷盘的维护命令。
- REWRITE：请求整理持久化文件的维护命令。
- 审计：为事后追责和排查保存的受控管理操作记录，记录来源、主体、动作、目标、时间和结果，不等同于普通调试日志。
- 幂等：重复执行相同请求不会增加额外副作用；是否成立由具体操作契约定义。
- 脱敏：隐藏或概括敏感信息，以减少秘密泄露。
