## 本轮范围

本轮针对连接请求串行派发与排队行为进行验证，重点检查协议协商失败后的队列处理、协议错误的响应先后关系，以及客户端半关闭后的请求和响应排空。另记录网络正确性测试与网络压力测试的实际结果。

术语说明：HELLO 是用于协议版本协商的请求；AUTH 是用于身份认证的请求；GET 是用于读取数据的请求；TCP 半关闭是客户端结束发送数据、但仍保持接收服务端响应的连接状态。

## 期望数据

- 网络正确性测试模块 `net_correctness_test`：既有协议解析、会话和连接行为断言全部通过；本轮重点覆盖请求顺序、失败处理与半关闭排空。
- 网络压力测试模块 `net_stress_test`：处理 100,000 个请求；输入统计为 2,400,000 字节，输出统计为 4,000,000 字节；请求无遗漏，测试正常结束。
- 本轮耗时和吞吐量作为当前测试环境下的观测值记录，不作为跨环境的固定性能门槛。
