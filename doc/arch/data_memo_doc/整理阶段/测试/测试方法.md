## P50，P99，P999测试方法

每个请求先得到一个延迟值：**完成时间减去提交时间**。收集到的延迟样本再统一排序，按样本在排序结果中的位置计算 P50、P99、P999；不是逐个请求直接归入某个 Px。

- 例如有 1000 个延迟样本，排序后约第 500 个是 P50，第 990 个是 P99，第 999 个是 P999。当前测试用线程级蓄水池保留部分样本，因此分位数是基于这些样本计算的。

## QPS测试方法

在一个时间段内（比如30s），去记录处理了多少个请求

QPS = 处理请求数 / 处理时间

## 命中率计算

命中率 = 缓存读取到数据的读请求数量 / 总共的读请求数量
