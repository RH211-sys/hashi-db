# 数据存储层的需求列表

## 基本操作

### 定义新的数据类型

- 服务端定义好结构体/类，启动的时候将其读取并加入到数据类型集合中

### 新增数据

- 传入格式：ADD， 变量名， 数据类型，值
- 返回：操作码

### 查找数据

- 传入格式：GET，变量名，查询指针
- 返回：操作码，查询的值放在指针中

### 删除数据

- 传入格式：DEL，变量名
- 返回：操作码

### 修改数据

- 传入格式：MOD，变量名，数据类型，值
- 返回：操作码

### 缓存内容持久化

- 调用一个bool接口，直接进行操作，返回操作码

### 磁盘内容导出

- 调用一个bool接口，直接进行操作，返回操作码

## 其他

1. 通过调用结构，存储基本的数据类型

   > int, long long, string
   > datetime有时间就做，没时间先不做，后期再补

2. 需要建立缓存和磁盘中的关系
