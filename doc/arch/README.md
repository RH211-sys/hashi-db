# 总体架构

主要分为6层：

- 存储
- 管理
- 日志
- 执行
- 命令解析
- 网络

另外两个是第三方库和common模块



## 存储层

- 缓存热点数据集，并拥有持久化功能（暂时不考虑崩溃恢复，为了高性能）

- 自定义数据类型

### 架构

- **读线程池 + 缓存写单线程 + 磁盘单线程**，这三组线程各自独立，写好各自模板，任务处理完后返回future，一般待cache层进行**异步续延链**
- **读并发，写串行，读写互斥，写优先防读饥饿的读写锁**，全局控制`缓存数据`
- 磁盘模块串行处理
