# 数据存储层的需求列表

## 基本操作

### 新增数据

- 在缓存中增加数据：

  用户通过调用接口，在缓存中写入**新**数据，
  可能是基本数据，可能是自定义数据

  > 取消在磁盘中新增数据的方案，如果要立即持久化，用户需要调用接口
  > 因为直接写入磁盘不如先写入缓存后再写入磁盘，这样可以一定程度上避免用户写错后删除，进行多次磁盘IO

### 查找数据

- 用户通过调用接口查找数据，需要返回对应的值

### 删除数据

- 用户通过调用接口删除数据，返回操作是否成功，若失败最好返回原因

### 修改数据

- 用户通过调用接口修改数据，返回操作是否成功，若失败最好返回原因

## 数据类型

键值对，键指变量名，

- 值：数据类型（基本类型/自定义类型），数据实体

## 其他

1. 通过接口调用，能够存储自定义数据

2. 通过调用结构，存储基本的数据类型

   > int, long long, string
   > datetime有时间就做，没时间先不做，后期再补

3. 需要建立缓存和磁盘中的关系

   - 详见可行性分析（策略方案）
